DGReader 鲨鱼版 v1.04 By FL
========================

读取 RPG Maker 游戏的对话框 / 战斗播报 / 战斗日志 / 变量，
按项目 → 场景 → 规则的方式管理预设，直接通过 BLE 驱动负鼠振动。
独立运行，不依赖其它控制软件。


第一次使用
----------
1. 解压到任意目录。
2. 双击 start.bat，浏览器打开 http://127.0.0.1:17872。
3. 进入【游戏 / 安装】：
   - “浏览…”选择游戏目录（例如 D:\Games\YourGame）
   - 点“安装插件”
   - 可点“检查状态”确认“已安装 / 已注册”
4. 进入【设备】：首次使用先在 Windows 配对负鼠（见下方），然后点“扫描附近负鼠”，选中设备并连接；地址会自动记住。
5. 进入【输出】：选择“直接驱动负鼠（BLE）”，保存。
6. 进游戏，规则触发时直接振动。

首次配对负鼠：
  设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙 → 显示所有设备
  → 选择负鼠的设备名（数字+英文）→ 配对完成
  → 回到 DGReader → 设备 → 扫描附近负鼠 → 使用选中 → 连接

卸载插件：同一个【游戏 / 安装】页点“移除插件”（会备份 plugins.js）。


顶部状态灯
----------
- 游戏灯：绿色 = 游戏插件已连上；红色 = 未连接
- 设备灯：绿色 = 负鼠已连接；黄色 = BLE 服务已启动但未连接；红色 = 未启动

项目栏（标题下方）可以快速切换项目和场景。


项目 / 场景
-----------
- 一个项目 = 一个游戏（一个游戏目录）
- 项目名可重命名；不同项目有独立的变量/开关映射和规则
- 一个场景 = 同一游戏的一套预设（不同章节/玩法）
- 场景可新建、重命名、删除、切换
- 切换项目/场景会立刻切换整套规则

预设导入导出（【游戏 / 安装】页）：
- 导出当前场景 = 导出一套规则预设（.json）
- 导入到当前场景 = 用文件替换当前场景规则
- 导出项目 / 导入项目 = 整个项目（含所有场景），导入会新建项目，不覆盖


编码兼容
--------
安装/检查时会检测 plugins.js 的编码，并在状态里显示：
- UTF-8
- UTF-8 BOM
- GB18030 / GBK
- Shift-JIS

安装和移除只对插件条目做 ASCII 字节级插入/删除，不会把整个文件
重新转码，原文件其它字节保持不变（操作前有备份）。
所以 GBK / Shift-JIS 的 plugins.js 不会被写坏。

不会默认“统一转 UTF-8”：
只转 plugins.js 而不同时处理 index.html、其它 JS/JSON，反而会让游戏打不开。
如果游戏本身文字就是乱码，那是游戏数据/字体问题，hook 只能原样读取，
需要在游戏侧修编码或换正常版本。

语言 / Language
--------------
- 内置：中文、日本語、English，顶部“语言”下拉切换，立即生效并记忆。
- 其他语言：选择“其他语言…”会提示使用浏览器自带翻译，并显示可能使用的服务商
  （Chrome 通常 Google，Edge 通常 Microsoft，以浏览器实际为准）。
- 浏览器翻译只用于界面；游戏文本、日志、代码、路径不会参与翻译。
- 浏览器翻译需要用户在浏览器菜单里触发，工具本身不能代替点击。
- 动态内容更新后，可能需要再点一次浏览器的“翻译”。


OCR（附赠功能）
----------
用于 Unity、独立 AVG 等无法安装插件的游戏。只使用 Windows 自带 OCR，不下载
Tesseract/PaddleOCR 等额外模型。

1. 先安装系统 OCR 语言包：
   Windows 设置 → 时间和语言 → 语言 → 添加中文/日文/英文，
   并安装“光学字符识别”可选功能。
2. 进入【OCR（附赠功能）】→“启动 OCR 服务”。
3. 点“截屏并框选区域”，在截图上拖动框选游戏对话框。
4. 选择识别语言，点“测试识别”确认识别效果。
5. 设置间隔（建议 1500–2500ms），点“开始监视”。
6. 在【规则】里把触发来源选为“OCR 文本”，只支持“包含 / 正则”。

注意：
- OCR 有 1–3 秒延迟，快速滚动/逐字显示会漏读；请把游戏文字速度调慢。
- OCR 只在前台可见时有效；独占全屏可能截不到，建议无边框窗口。
- OCR 不支持变量、图标、颜色、播报 ID。
- 首次识别会初始化引擎，可能稍慢；之后会复用。


规则
----
【规则】页：
- 左侧列表：勾选框一键启用/停用、测试、编辑、删除
  （“测试”会直接让设备按这条规则的 A/B 输出振动 3 秒，方便调试）
- 右侧编辑：
  触发来源：对话框文本 / 战斗播报 / 战斗日志 / 播报 ID / 变量数值 / 开关状态 / 高级表达式
  匹配：包含 / 正则 / 图标 / 颜色 / 等于 / 前缀 / ≥ / ≤ / 开关
  输出 A / B 可同时启用：
    波形（持续/呼吸/潮汐/心跳/脉冲/渐强/渐弱/锯齿/随机/按摩/连击/波浪/敲击/蠕动 + 自定义）
    强度 0–200
    秒数（0 = 持续到条件不成立）
- 保存立即生效

示例：
- 对话框文本 包含 “游泳” → A 35 / 呼吸 / 3 秒
- 战斗播报 正则 “今天天气怎么样|你吃了吗” → A 70 / 持续 / 3 秒
- 正则里的 | 表示“或”；要“和”请用高级表达式 &&
- 变量 ≥ 80（选 estrus）→ B 50 / 潮汐 / 0 秒


波形导入导出
------------
【设备】页底部“波形库”：
- 导入 .pulse：支持 Dungeonlab+pulse 文本格式（DG-LAB 生态使用的 .pulse）和 JSON
  （文本格式会从 atoms/强度序列转成 0–100 的振动包络）
- 导出：把当前选中的波形保存为 .pulse
- 删除自定义：只删除导入的波形，内置波形不受影响

自定义波形会出现在规则和设备的波形下拉框里（带 * 标记）。


设备
----
负鼠官方协议：0x180C/0x150A 写，B3 设强度，B0 每 100ms 发振动包络（每通道 4×25ms）。
- A/B 独立强度与波形
- 测试 3 秒 / 停止
- 断开或停止自动归零

连不上时：
1. 关闭其它正在占用设备的程序
2. 负鼠开机，必要时连按 5 次开机键
3. 靠近电脑；仍失败可在 Windows 蓝牙设置里先配对一次


常见问题
--------
Q: 游戏灯不绿
A: 插件是否安装成功、游戏是否重启、端口 17870 是否被占用。

Q: 设备灯黄但不绿
A: BLE 服务在运行，但还没连上负鼠 → 去【设备】点连接。

Q: 规则不触发
A: 1) 规则勾选框是否启用；2) 输出是否选了“直接驱动负鼠”；
   3) 条件是否匹配（看【读取】页原文/播报 ID）；4) 设备灯是否绿。

Q: 波形和官方 App 不一样
A: 负鼠是振动设备，官方协议只接受 0–100 振动包络；
   本工具按包络模型生成波形，不是 Coyote 电刺激波形。
   .pulse 的 atoms 只能近似转换成振动包络。

Q: 影响游戏/存档吗
A: 插件只读 hook，不改游戏逻辑；安装只改 plugins.js（有备份）。


已知边界
--------
- 设备层目前只支持负鼠（Opossum 1.0），郊狼还没接。
- 变量/开关映射目前随项目继承；新建项目默认使用通用映射，
  其它游戏需要在项目文件里调整（后续会加界面编辑）。
- MZ 的 API 同名，但未实机验证。
