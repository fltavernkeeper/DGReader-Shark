# DGReader Shark / DGReader 鲨鱼版

给 **负鼠（Opossum）振动控制器** 连接 RPG Maker 等文字游戏使用的文字读取与规则触发工具。

读取游戏对话框、战斗播报、战斗日志，按规则直接驱动负鼠振动；另附带 Windows OCR 模式，用于 RPG Maker MV/MZ 之外、无法安装插件的文字类游戏。

## 功能

- 读取对话框文本、角色名、图标/颜色、战斗左上角播报、战斗日志、变量/开关
- 可视化规则：触发条件 + A/B 双通道输出（波形、强度、秒数）
- 每个游戏独立项目，每个项目可建多个场景预设
- 规则一键启用/停用，单条规则一键测试
- 负鼠 BLE 直连：B3 强度 + B0 25ms 波形
- 波形库导入/导出（`.pulse` / JSON）
- 内置中文 / 日本語 / English，其他语言可用浏览器翻译
- OCR（附赠）：Windows 自带 OCR，框选屏幕区域识别文字后交给规则

## 首次连接负鼠（Windows 配对）

Windows 需要先配对一次，之后 DGReader 会自动记住地址：

1. 打开 Windows **设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙**
2. 点 **显示所有设备**（不同版本可能叫“其他设备”）
3. 选择负鼠的设备名（数字+英文）
4. 配对完成后回到 DGReader → **设备** → **扫描附近负鼠**
5. 选择负鼠 → **使用选中** → **连接**

地址会自动记住，以后打开软件可直接连接。

## 快速开始

1. 解压发布包。
2. 双击 `start.bat`，打开 `http://127.0.0.1:17872`。
3. 进入【游戏 / 安装】，选择游戏目录并安装插件。
4. 进入【设备】，扫描附近负鼠并连接。
5. 进入【输出】，选择“直接驱动负鼠（BLE）”。
6. 在【规则】里添加条件，保存后进游戏测试。

OCR 模式需要先在 Windows 设置中安装对应语言的“光学字符识别”组件。

## 范围

- 插件模式：RPG Maker MV / MZ（MV 1.x 实机验证，MZ 未实机验证）
- OCR 模式：Unity、独立 AVG 等能显示文字的游戏
- 设备：负鼠 Opossum（直连 BLE，无需额外软件）
