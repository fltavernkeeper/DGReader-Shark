规则输出字段

      

        每条规则可独立设置 A / B：

        · 是否启用

        · 波形

        · 强度 0–200

        · 秒数（0 表示持续到条件不成立）


        A/B 的波形互不影响，设备层会按 25ms 粒度分别生成 B0 数据。

        强度最终仍受设备自身限制。

OCR（附赠功能）给 RPG Maker MV/MZ 之外的文字类游戏

      

        

          这是附赠功能，用于 RPG Maker MV/MZ 之外、无法安装插件的文字类游戏
          （Unity、独立 AVG 等）。原理是调用 Windows 自带 OCR 识别屏幕上的文字，
          不是 hook，所以有延迟，也会受字体、背景、文字速度影响。
        

        

          使用前请先安装系统 OCR 语言包：

          Windows 设置 → 时间和语言 → 语言 → 添加中文/日文/英文 →
          安装“光学字符识别”。

          识别语言列表只显示系统已安装的 OCR 语言。
        


        

          
          
          未启动
        


        

          
          
        


        

          
          
        

        
点击按钮后，在截图上按住左键拖动，框住要识别的文字区域


        

          
          
        


        

          
          
          
          
        


        
识别结果会显示在这里。


        

          识别出的文字会作为【规则】里“OCR 文本”来源的输入；文字稳定约 2 帧后才会触发规则。
不在规则中勾选 OCR 文本来源就无法触发规则。
        


        

          OCR 有 1–3 秒延迟，快速滚动/逐字显示会漏读；请把游戏文字显示速度调快、自动翻页速度调慢。

          只支持关键词/正则规则，不支持变量、图标、颜色；需要游戏保持前台可见。

负鼠 BLE官方协议 180C / 150A · B3 强度 + B0 波形

      

        

          
          
          
        

        

          
          
          
        

        

          首次使用：Windows 设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙 → 显示所有设备 → 选择负鼠设备名（数字+英文）。

          配对完成后回到这里，点“扫描附近负鼠” → 使用选中 → 连接。地址会自动记住，以后可直接连接。

          扫描约 6–30 秒，请让负鼠开机并靠近电脑。

波形库（.pulse 导入/导出）

          

            
            
          

          

            
            
            
          

          

            支持 Dungeonlab+pulse 文本格式，以及 JSON；可一次选择多个文件。

            导入限制：单个波形最多 30 段、4800 个点（约 120 秒）；多段按顺序合并。外部官方格式每点按 0.1 秒展开，特殊头部/参数可能无法完全还原。
          

          

            获取波形
            

              第三方波形库：dglab-pulse-collect

              作者：zakotoys

              许可证：MIT

              说明：不同设备/版本的波形导入后可能和原工具效果有差异。
